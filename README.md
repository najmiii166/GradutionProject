MentorLink 🎓

MentorLink is a full-stack mentorship platform designed to connect students with mentors and support knowledge sharing, career guidance, and professional growth.

## 🚀 Features

- User Registration and Login
- Student and Mentor Profiles
- Mentor Discovery
- Mentor-Student Matching
- User-Friendly Interface
- Full-Stack Web Architecture

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## 💡 Project Purpose

The goal of MentorLink is to make mentorship more accessible by providing a digital platform where students can connect with mentors based on their learning and career needs.
